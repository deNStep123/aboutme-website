# aboutme-website

A personal one-page portfolio website hosted on my own Linux server.

The project is designed not only as a personal portfolio, but also as a practical infrastructure and DevOps learning project. It demonstrates my skills and experience in system administration, networking, Linux, server security, deployment, and infrastructure management.

## About the project

The website presents information about me, my technical background, skills, projects, and experience.

The server infrastructure behind the website is managed and maintained by me. The project is used as a practical environment for learning and applying real-world system administration and DevOps practices.

This includes:

- Linux server administration
- Network configuration and troubleshooting
- SSH access and hardening
- Firewall configuration
- Server security
- Application deployment
- Git and GitHub workflow
- CI/CD automation
- Monitoring and maintenance
- Backup and recovery practices

The infrastructure is intentionally kept relatively small and understandable, with the goal of building practical experience rather than introducing unnecessary complexity.

## Project structure

The repository contains the website source code, documentation, and configuration related to the project.

Infrastructure documentation is available in the `docs/` directory.

Sensitive information such as private keys, credentials, public IP addresses, and other environment-specific secrets is not stored in the repository.

## Goal

The main goal of this project is to build and maintain a real, publicly accessible service while continuously improving my skills in Linux administration, networking, security, and DevOps.
